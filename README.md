# СТО GRAND AM Autocenter — лендинг (українська мова)

Чистые HTML/CSS/JS, без фреймворков и внешних шрифтов. Откройте `index.html` или запустите `python3 -m http.server 8080`.

## Структура
```
index.html            разметка страницы
css/styles.css        стили (mobile-first, светло-серая тема, красные и синие акценты)
js/script.js          меню, слайдер, статус «відчинено/зачинено», форма записи
js/config.js          адрес Worker для формы (formEndpoint)
assets/images/        все изображения сайта (локально)
worker/               Cloudflare Worker: принимает заявки и отправляет в Telegram (см. worker/README.md)
```

## Форма записи
Поля: імʼя, телефон, марка автомобіля, короткий опис проблеми + согласие на обработку данных.
Заявки идут через Cloudflare Worker в Telegram-чат владельца. Пока `formEndpoint` в `js/config.js` пустой,
форма показывает сообщение с телефоном и Telegram.

1. Изображения-заглушки в `assets/images/` (gallery-1.svg, gallery-2.svg, gallery-3.jpg) — на реальные фото работ.
   Новые слайды добавляются в `#sliderTrack` в index.html, точки создаются автоматически.
2. Ссылки Telegram/Viber построены по номеру +380 68 895 6363. Если у СТО есть username в Telegram — замените `https://t.me/+380688956363`.
3. После выбора домена добавьте `<link rel="canonical">`, sitemap.xml и robots.txt, подключите Google Search Console.
4. Создайте карточку в Google Business Profile — для местных запросов она важнее самого сайта.
5. Добавьте страницу политики конфиденциальности (с реальными данными владельца) и ссылку на неё у чекбокса согласия;
   укажите, что заявки передаются через Cloudflare и Telegram.

Услуг в брифе только две: гальмівні системи и рульове керування та підвіска. Других услуг, цен и гарантий на сайте нет.
